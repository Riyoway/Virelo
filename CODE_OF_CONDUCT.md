# Code of Conduct

Virelo contributors are expected to keep project spaces respectful, focused, and safe.

## Expected behavior

- Discuss ideas and code without attacking people.
- Give specific, constructive feedback.
- Respect different backgrounds, experience levels, and communication styles.
- Keep private information and security reports out of public discussions.

## Unacceptable behavior

Harassment, discrimination, threats, sexualized attention, deliberate disruption, and publishing another person's private information are not permitted.

Maintainers may edit or remove contributions and restrict participation when this code is violated. Serious or sensitive reports should be sent privately through the repository's security reporting channel.
