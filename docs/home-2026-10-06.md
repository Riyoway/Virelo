# Home improvements — 2026-10-06

The app Home (not the marketing landing page) is now a content-led local streaming library. Both npm and browser-only implementations use the same shelf-curation rules.

## Content and interactions
- Continue watching uses recent playback updates and one entry per series.
- Up next selects the next available numbered episode after completed episodes, without wrapping or duplicating an in-progress series.
- Unwatched discoveries include older library items and rotate deterministically each day. A new series starts at its first episode.
- Movie shelves offer 90-minute options using actual durations.
- Genres come only from available metadata; small/missing genre groups do not create filler sections.
- Favorites, including portrait clips, are preserved.
- Recently added stays chronological. Movies selects titles outside that shelf before the 24-item payload limit, so older films remain reachable even in large libraries.
- The Movies row excludes Recently added titles in both For you and Movies views. Small libraries omit this redundant row, while movie-category hero candidates and Browse library remain available.
- Identical discovery collections are omitted even if shuffled or represented by a different episode of the same series. Recent takes priority, then unseen/short-film/series/genre collections; Continue watching, Up next and Favorites are intentionally preserved.
- For you / Movies / Series filter Home shelves.
- Featured titles have manual navigation, useful metadata, artwork fallbacks and a direct Play/Resume action. No timed title swaps or autoplay trailer.
- Horizontal shelves support wheel, touch, arrow buttons and keyboard navigation, including shelves appearing after a data refresh.
- Empty categories, failed requests, missing artwork and long titles have explicit handling.

## Data and privacy
- npm curates a single SQLite catalog snapshot after applying existing library visibility rules; the API returns bounded shelves, not the full catalog.
- Browser-only Home reads local records and hydrates thumbnails once per displayed title rather than for every library item.
- No external ranking, new tracking, AI-generated recommendation claims or additional metadata service is introduced.

## Verification

- npm additionally verifies hidden-library exclusion across every Home shelf.
- Curation regressions cover complementary movie shelves, small libraries (0/1/6/24 titles), partial backfilling, mixed series/portrait libraries, history/favorites preservation and deterministic bulk imports.
- Empty-category messaging uses actual movie/series candidates, not only Recently added. Older movies stay available when the latest 24 additions are series.
